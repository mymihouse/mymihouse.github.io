Bienvenue dans MymiHouseBoucletteBuilder

Dessinez vos plans de maison avec des cotes précises, visitez-les en 3D et exportez un dossier de plans (plan, coupe, façades, plan de masse) prêt pour un permis de construire.

Aide rapide

Dessiner les murs

  • Outil Mur extérieur (M) : cliquez point par point, double-clic ou Entrée pour terminer. Les murs s'accrochent aux angles droits et aux murs existants.
  • Pendant le tracé, tapez une longueur (ex. 4,50 en mètres ou 450 en cm) puis Entrée pour un mur à la cote exacte.
  • Outil Pièce rect. (R) : tirez un rectangle pour créer 4 murs d'un coup.
  • Les pièces et leurs surfaces se créent automatiquement dès que les murs sont fermés. Cliquez sur une pièce pour la renommer.

Portes, fenêtres, meubles

  • Choisissez un type d'ouverture puis cliquez sur un mur. Glissez-la pour la déplacer ; ses dimensions et son sens d'ouverture sont dans le panneau de droite.
  • Bibliothèque : cliquez sur un meuble puis sur le plan pour le poser. R le fait pivoter.

Assistant ✨

  • Bouton ✨ Assistant : tapez une phrase comme « agrandis la chambre 2 de 30 cm vers la salle de bains », « fenêtres en gris anthracite à 3 vantaux » ou « bardage bois sur la façade nord ».
  • La première fois, cliquez sur ⚙ et collez une clé Google Gemini gratuite (lien et explications dans la fenêtre). Chaque modification s'annule avec ⌘Z ou le bouton « Annuler ».

Étages (plusieurs niveaux)

  • La barre Niveaux en haut du plan permet de passer d'un niveau à l'autre. ＋ Étage crée un étage avec les mêmes murs extérieurs.
  • Le niveau voisin s'affiche en bleu clair sous le plan pour aligner les murs. Nom, hauteur sous plafond, ajout d'un niveau en dessous et import d'un niveau depuis un autre fichier sont dans le panneau de droite.
  • Nommez une pièce Trémie (ou « Vide sur séjour ») pour percer le plancher à l'endroit de l'escalier.
  • La 3D, les façades, la coupe et le PDF montrent tous les niveaux. En 3D, « Niveaux » permet de n'afficher que jusqu'au niveau choisi pour voir l'intérieur.

Toiture, coupe, parcelle

  • Toiture : ajoutée automatiquement sur l'emprise des murs (4 pans par défaut). Réglez la pente, le débord et le type dans le panneau.
  • Ligne de coupe : tracez 2 points sur le plan ; la vue « Coupe » et le PDF l'utilisent.
  • Parcelle : cliquez les coins du terrain (double-clic pour fermer) pour obtenir le plan de masse avec les distances aux limites.

Reprendre un plan existant (PDF ou photo)

  • Importer PDF : le plan s'affiche en transparence sous votre dessin.
  • Mettre à l'échelle : cliquez 2 points dont vous connaissez la distance réelle (par ex. les deux extrémités d'une cote « 4,50 »), tapez cette distance, Entrée.
  • Redessinez ensuite les murs par-dessus. Opacité, rotation, déplacement et verrouillage sont dans le panneau de droite.

Navigation

  • Molette : zoom. Glisser sur le vide, bouton droit ou Espace + glisser : déplacer. A : ajuster la vue.
  • Suppr : supprimer la sélection. ⌘Z / ⇧⌘Z : annuler / rétablir. Échap : annuler l'outil en cours.
  • Vue 3D : glisser pour tourner, molette pour zoomer, « Visite à pied » pour se promener dans la maison.

Le projet est sauvegardé automatiquement dans ce navigateur. « Enregistrer » crée un fichier .json que vous pouvez rouvrir ou partager.
